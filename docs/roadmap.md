# 路线图

## 下一个版本：多标签选片，按标签导出

### 要解决的问题

一个文件夹里的照片常常要分给几个去处：一场活动拍了好几个人，每个人要一份；同一批照片既要交给客户，又要发社交平台，还要留作品集。现在只有“选中 / 排除 / 星级”这一个维度，只能分几次选、分几次导出。

### 要做成什么样

1. 选片的时候可以随时新建标签（起个名字），并立即用它标记照片。
2. 一张照片可以带多个标签。
3. 可以按标签筛选，只看某个标签下的照片。
4. 导出时每个标签导出到一个文件夹，文件按标签重命名。
5. 一张照片带多个标签时，每个标签的文件夹里都导出一份。

举例：照片 `DSC_0012` 带“小明”和“合影”两个标签，`DSC_0015` 只带“小明”。导出后：

```
导出目录/
  小明/
    小明_001.JPG    （原 DSC_0012）
    小明_002.JPG    （原 DSC_0015）
  合影/
    合影_001.JPG    （原 DSC_0012）
```

### 初步设计

这些是按现有代码结构做的设想，开工时再逐条确认。

**保存**

- 标签和“选中 / 排除”、滤镜、裁剪一样，按文件夹保存在选片进度里（`save_session`），键是 `shotKey`，RAW+JPG 一对共用一组标签。
- 进度里另存一份这个文件夹的标签表：名字、颜色、顺序。改名、删除标签只改这张表，照片上记的是标签的编号而不是名字。
- 新建过的标签名要不要跨文件夹记住、下次直接选：待定。

**选片界面**

- 查看页底部工具栏和列表的多选栏各加一个标签入口：列出已有标签，点一下打上或去掉，最下面是“新建标签”。
- 前 9 个标签有快捷键，可在“设置 → 快捷键”里改；现在 `0`–`5` 是星级，所以要另选一组按键。
- 列表的格子和查看页标题旁显示照片带的标签（色点，放得下时带名字）。
- 顶部筛选栏在“全部 / 已选 / 未标记 / 排除”之外加按标签筛选，可以多选。
- 连拍叠成一格时，在列表里打标签作用于整组，在查看页里只作用于屏幕上那一张，和现在的星级、标记一致。

**导出**

- 导出面板加一项“按标签分文件夹”：打开后，目标文件夹下每个标签建一个子文件夹，名字就是标签名（去掉文件名里不能用的字符）。
- 重命名规则加 `{tag}`，默认规则是 `{tag}_{seq}`；序号在每个标签里各自从头数。不重命名时保留原文件名。
- 带多个标签的照片在每个标签的文件夹里各有一份。套了滤镜或裁剪的照片只渲染一次，再复制到其余文件夹。
- 现有的规则照旧：RAW / JPG 的取舍，实况照片的 MOV 跟着静态照片走，同一个文件夹里重名时加 `_2`、`_3`。

### 还没定的

- 没有标签的照片：不导出，还是放进一个“未分类”文件夹。
- 和“选中”的关系：按标签导出时是导出带标签的全部照片，还是只导出其中已选中的。
- 标签要不要同时写进文件的 XMP 关键词（`dc:subject`），让 Lightroom、Bridge 等软件也能看到。写的话沿用星级的规则：RAW 不改写，写不进就写 `.xmp` 旁车文件。
- 手机上的入口放在哪里。
- 局域网传输要不要也能按标签选照片。
